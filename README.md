# Rubka Chart Bot

Rubka Chart Bot is a simple Python bot for creating different types of charts using Matplotlib. The bot guides the user through the chart creation process and generates the final chart based on the provided data.

## Features

* Line charts
* Vertical bar charts
* Horizontal bar charts
* Pie charts
* Up to 20 values per data set
* Custom chart titles
* Custom X and Y axis names
* Cancel chart creation at any step
* Generated charts are automatically deleted after 15 seconds

## Requirements

* Python 3.10 or newer
* Matplotlib
* Rubka

Install the dependencies with:

```bash
pip install -r requirements.txt
```

## Usage

Run the bot with:

```bash
python main.py
```

After starting the bot, use `/start` and follow the instructions to create a chart.
